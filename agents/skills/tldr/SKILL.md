---
name: tldr
description: Make responses concise, clear, and easy to scan. Use when the user asks for TLDR, short answers, "be brief", "too long", "not a novel", "少写点", "简短", "别像小说", or wants the answer compressed into practical chunks.
---

Answer in TLDR style: lead with the answer, use short paragraphs or bullets, and avoid essay-like background. Keep concrete actions, risks, file paths, commands, and verification status. If complex, give the shortest useful answer first and ask what to expand next.
